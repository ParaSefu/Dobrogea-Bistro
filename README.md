# Dobrogea Bistro

Site static demonstrativ pentru un restaurant fictiv din Constanța. Folosește HTML, CSS și JavaScript simplu, fără biblioteci sau proces de compilare.

## Deschidere

1. Deschide folderul `restaurant` în File Explorer.
2. Dă dublu clic pe `index.html` pentru a-l deschide în browser.

Nu este necesară instalarea unui program sau pornirea unui server local. Fotografiile, fonturile și harta se încarcă de pe internet; fără conexiune, unele elemente vizuale externe pot lipsi.

## Fișiere

- `index.html` — conținutul paginii și formularul demonstrativ.
- `styles.css` — paleta, aspectul responsive și animațiile.
- `script.js` — meniul pentru mobil, filtrarea meniului, validarea și confirmarea formularului demonstrativ.

## Despre conținut

Dobrogea Bistro este un concept fictiv. Meniul, prețurile, programul și poziția de pe hartă sunt demonstrative și nu descriu o afacere sau o adresă reală. Fotografiile sunt ilustrative și provin de la Unsplash.

Formularul verifică datele în browser și afișează o confirmare demonstrativă, dar nu trimite și nu salvează informații. Butonul WhatsApp deschide un mesaj pregătit fără număr de telefon; utilizatorul alege conversația sau destinatarul. Pentru folosire reală, conectează formularul la un serviciu de rezervări și configurează un număr WhatsApp autorizat.
